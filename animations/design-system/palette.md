# Paleta de colores

## Filosofia

> [SETUP REQUIRED] Run `/project-setup` to generate this palette.
> The wizard will use `ui-ux-pro-max` to create a coherent color system
> based on your project's mood and brand.

## Tokens — Fondos

| Token            | Hex       | Uso                                          |
| ---------------- | --------- | -------------------------------------------- |
| `bg-deep`        | `#------` | Fondo base del canvas                        |
| `bg-base`        | `#------` | Superficie principal, ligeramente elevada    |
| `bg-elevated`    | `#------` | Cards, paneles, cajas de codigo              |
| `bg-subtle`      | `#------` | Superficies secundarias, separadores         |

## Tokens — Foreground (texto)

| Token            | Hex       | Uso                                          |
| ---------------- | --------- | -------------------------------------------- |
| `fg-primary`     | `#------` | Texto principal, titulos                     |
| `fg-secondary`   | `#------` | Texto secundario, subtitulos                 |
| `fg-muted`       | `#------` | Captions, labels, metadata                   |

## Tokens — Accents

| Token            | Hex       | Rol                                          |
| ---------------- | --------- | -------------------------------------------- |
| `accent-warm`    | `#------` | Highlights, CTAs, reveals                    |
| `accent-warm-glow` | `rgba(...)` | Glow ambiental en key moments           |
| `accent-cool`    | `#------` | Estructura, diagramas, tech                  |
| `accent-cool-glow` | `rgba(...)` | Glow sutil para elementos secundarios   |
